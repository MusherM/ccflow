CCFlow

节点式 Claude Code 会话管理器

💡 解决什么问题？

  • Claude Code 会话越积越多，找不到之前那个精彩的对话
  • 想回顾某个 feature 的开发过程，却只能翻历史记录
  • 多 feature 并行开发时，切换分支来回操作太麻烦

CCFlow 把 Claude Code 的每一次会话变成一个「节点」，自动保存 commit，记录你的工作轨迹。

✨ 能做什么？

📍 节点即会话 🔄 自动 commit 🌲 可视化节点图 🔀 多分支合并 📝 智能 commit 信息

🚀 快速开始

在 Git 仓库中运行 ccflow 即可。

使用 Tab 新建节点 · Shift+Tab 新建分支 · 空格+m 合并节点
